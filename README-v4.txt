NEXTPLAY v4｜首頁與分類頁優化

更新內容：
1. 保留 v3 的全部文章、閱讀目錄、作者資訊、分享功能與延伸閱讀。
2. 首頁最新文章、遊戲、體育專區增加導覽連結，文章卡片改善陰影、間距與滑鼠互動。
3. 遊戲與體育分類頁增加文章總數、排序（最新／最早／標題）及載入更多（每次 6 篇）。
4. 手機版卡片排版與導覽一致化。

本機測試：進入 nextplay 資料夾，在命令提示字元執行 python -m http.server 8000，瀏覽 http://localhost:8000。

發布文章：延續 v3 流程，新增 articles/*.html 並在 data/articles.json 登記；首頁和分類頁會自動更新。

注意：目前只有 6 篇示範文章，單一分類只有 3 篇，因此「載入更多」按鈕會隱藏；同分類超過 6 篇後會自動出現。
